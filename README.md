# Mother-Maiden-Crone-Repo

Mother Maiden Crone is a game set during a witch trial in Salem, MA. It's inspired by the story of my (Sally Nagle's) maternal ancestor, Rebecca Nurse. It is made in Unity. 

Challenges:
1. Integrating an advanced, choice-based dialogue system.
2. Creating and designing a narrative with 12 unique characters.
3. Implementing character animations and transitions.
4. Creating a puppet-show artstyle for unique aesthetics.

This game is still in progress.
